## Writing Tips

1. Use h2 (`##`) for main sections
2. Use h3 (`###`) for subsections
3. Include code examples where relevant
4. Use images to illustrate complex concepts
5. Break up long paragraphs for readability
6. Conclude with a summary or call to action

## Frontmatter Fields Explained

- `title`: Main title of your post
- `description`: Brief summary for SEO and previews (150-160 characters ideal)
- `date`: Publication date (YYYY-MM-DD)
- `author`: Post author (defaults to site owner)
- `tags`: Array of relevant topics
- `category`: Main category for the post
- `status`: draft/published
- `cover_image`: Featured image path (optional)
