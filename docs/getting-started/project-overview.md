# Project Overview

MattKelly.io is a high-performance personal website that embraces boring technology principles and modern development practices. Built with Ruby on Rails 8 and styled with Tailwind CSS, it demonstrates how traditional technologies can create modern, lightning-fast web experiences.

## What This Project Is

A minimalist personal website that prioritizes:

- 🚀 **Performance** - Static site generation, minimal JavaScript footprint
- 🎯 **Content-First Design** - Markdown-based blog and documentation
- 🛡️ **Modern Practices** - Comprehensive test coverage, automated CI/CD
- 🎮 **Interactive Features** - Terminal emulator, DragonRuby tutorials

## Key Features

### Interactive Terminal Emulator
A fully functional browser-based shell with:
- Virtual filesystem using Filer.js and IndexedDB
- Persistent storage across page reloads
- Tokyo Night color scheme
- Real command execution (ls, cat, cd, pwd, etc.)

### DragonRuby WebAssembly Integration
Step-by-step game development tutorials with:
- 24 progressive lessons
- Live code editor with split-pane view
- Real-time WASM execution
- Interactive examples

### Markdown-Based Content
Simple content management through:
- Blog posts as markdown files
- Development documentation wiki (this!)
- Easy to write, easy to maintain

### GitHub Integration
- Activity heatmap visualization
- Automated deployment via GitHub Actions
- Open source and transparent

## Technology Philosophy

This project demonstrates that you don't need complex build tools, heavy frameworks, or JavaScript-heavy approaches to create a modern web experience. By embracing:

- **Rails 8** with native features (no build step needed)
- **Importmap** for JavaScript (browser-native ES6 modules)
- **Hotwire** for interactivity (Turbo + Stimulus)
- **ViewComponents** for organized UI
- **SQLite** for simplicity and speed

We achieve a fast, maintainable, and enjoyable development experience.
