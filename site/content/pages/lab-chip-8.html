CHIP-8 in Quartz

A small emulator used to exercise language, compiler, test, and browser-target boundaries.

Repository evidence

The pinned Quartz tree contains a reference implementation for classic base CHIP-8 and a smoke-test harness. The implementation models 4 KiB of memory, registers, timers, display state, input, opcode execution, and sprite behavior.

Browser path

The Lab concept compiles Quartz through a WebAssembly backend and connects the emulator to browser display and input. The source record establishes the emulator and tests; a browser build is a separately produced artifact with its own validation needs.

Why CHIP-8

CHIP-8 is small enough for the full machine model to remain inspectable while still exercising instruction decoding, state transitions, timing, input, graphics, and target-specific integration.

Boundary

No claim is made here about every opcode quirk, ROM compatibility, ROM licensing, audio timing, browser support, or the current availability of an interactive artifact.
