Preserved archive

DragonRuby tutorial experiment

A Rails-era attempt at an in-browser tutorial and game-runtime workspace.

Preserved material

Twenty-four Markdown tutorial sources remain under dragonruby/. Historical browser loaders, game data, and WebAssembly-related files remain under public/dragonruby/.

Current disposition

The tutorial sources are not rendered as lessons and the browser artifacts are excluded from the core static release. The archive records an implementation direction; it is not presented as a maintained learning product.

Execution boundary

No claim is made that the archived browser build currently executes correctly, safely, or compatibly with the site's serving headers. Restoration requires separate provenance, licensing, security-header, and browser validation.
