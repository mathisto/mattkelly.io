Architecture archive

Scribe

A private Rails system that turned natural-language entries into reviewable structured records.

Documented architecture

The Rails archive describes namespaced models for ingestions and event records, service objects for prompt construction and parsing, an Anthropic API adapter, confidence and review states, and a development-only interface built with ViewComponent and Turbo.

Asynchronous processing

A later iteration documented pending, processing, completed, and failed ingestion states; Solid Queue background jobs; retry handling; and Turbo Stream broadcasts. This is useful as an architecture record even though implementation reports contain manual-test gaps and unverified performance estimates.

Public boundary

Scribe itself remains private and is not part of the static portfolio. No utterance, prompt payload, health or habit record, database, credential, private endpoint, or user-derived aggregate is published.

Why preserve the architecture

The useful pattern is the separation of raw input, asynchronous interpretation, confidence, human review, and durable records. The private data is not necessary to explain that design.
