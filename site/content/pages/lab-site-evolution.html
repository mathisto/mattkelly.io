The site as a lab

Site evolution

Each implementation era exposed a different idea about what a personal site should own.

Rails application

The prior site combined a portfolio, blog, GitHub activity, an interactive terminal, DragonRuby experiments, documentation, and private Scribe development in a Rails 8 application. It demonstrated breadth, but made a professional portfolio responsible for application runtime and request-time integrations.

Static foundation

Foundation commit 9a4f54c replaced Rails with a dependency-minimal Quartz SSG, semantic source pages, deterministic clean builds, local assets, and a Caddy route contract. Rails remains recoverable through Git history.

Living resume

The current content system separates Work, Lab, Writing, and About; records claim status in a build-validated flat ledger; and publishes provenance alongside narrative. The site can change without hiding which statements are sourced and which remain personal accounts.

For the chronological record, see Site History.
