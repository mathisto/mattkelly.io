Implementation chronology

Site History

The portfolio has been a static page, a Rails application, an experiment host, and now a Quartz-generated living resume.

  1. Rails portfolio era

    Rails 8, ViewComponent, Stimulus, importmap, and a Tokyo Night interface supported the home page, projects, blog, CV, and references.

  2. Interactive experiments

    The site accumulated an in-browser terminal, GitHub activity, DragonRuby tutorial and browser artifacts, development documentation, and the private Scribe system. Some were complete features; others remained plans or partially validated experiments.

  3. Static foundation, 2026-07-16

    Foundation commit 9a4f54c removed the Rails runtime from the core portfolio, introduced the Quartz SSG and deterministic verification, preserved consented references and local assets, withheld privacy-unreviewed CV downloads, and retained historical recovery through Git.

  4. Living-resume content system

    The site now routes professional work, public Lab material, writing, biography, resume, references, current focus, provenance, and this history through a validated route manifest. Claim records make unsupported professional detail visibly personal rather than silently authoritative.

Recovery and preservation

The Rails era is preserved in Git history and the archival tag rails-final-2026-07-16. DragonRuby sources remain in their archive directories. Scribe code and private data are not migrated into public static content.
